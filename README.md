# a6-god-creator

Карточки для занятий

Редактор карточек с оформлением для занятий. Позволяет редактировать заголовки, добавлять фотографии и текст, кадрировать фото, сохранять проект и экспортировать листы A4 в PNG с разрешением 300 dpi.

## Версии

- **macOS, Apple Silicon:** актуальная версия. Книжный A4 содержит четыре карточки A6; альбомный A4 — две карточки A5. Проект из четырёх карточек в альбомном режиме распределяется на два листа.
- **Windows:** исходный код предыдущей автономной веб-версии сохранён в `windows/`. Она пока не поддерживает альбомный режим и проекты формата 3. Новая Windows-сборка не создавалась.

Готовую сборку для Mac можно найти в разделе Releases. Приложение собрано без нотариального заверения Apple. macOS может показать предупреждение при первом запуске.

## Сборка macOS

Необходимы macOS, инструменты разработчика Apple и Swift с macOS SDK. Сборка предназначена для Apple Silicon и macOS 13 или новее:

```sh
bash scripts/build-macos.sh
```

Готовые `.app` и архив находятся в `build/`. Настройки и фотографии редактируемых проектов хранятся в JSON; файлы фотографий сохраняются в проекте. Редактор работает локально, без сети.

## Совместимость проектов

Mac-версия открывает проекты форматов 1–3. Проекты с кадрированием и тремя фотографиями используют формат 2, а проекты, сохранённые в альбомном режиме, — формат 3. Предыдущая Windows-версия открывает форматы 1–2; обновление для формата 3 пока не выпускалось.
