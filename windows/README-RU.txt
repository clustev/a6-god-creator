КАРТОЧКИ A6 ДЛЯ WINDOWS

Подходит для 64-битной Windows на процессорах Intel и AMD. Установка и интернет для работы не нужны. Нужен современный браузер; предпочтительно Microsoft Edge. На Windows ARM программа может работать через эмуляцию, если она доступна в системе.

ЗАПУСК
1. Распакуйте архив целиком и откройте файл «Карточки A6.exe» двойным щелчком.
2. Откроется небольшое окно приложения, затем редактор в Microsoft Edge. Если Edge не установлен, откроется браузер по умолчанию. Если браузер сам не открылся, скопируйте адрес из окна приложения в адресную строку браузера.
3. Пока работаете, не закрывайте небольшое окно приложения: оно обеспечивает работу редактора. Когда закончите, сохраните проект, закройте вкладку и окно приложения.

КАРТОЧКИ И ТЕКСТ
• Новый проект содержит одну карточку. Кнопкой «+» можно добавить до четырёх карточек, менять их порядок или удалять.
• Выберите режим листа: книжный A4 с четырьмя карточками A6 или альбомный A4 с двумя карточками A5. В альбомном режиме карточки 1–2 находятся на первом листе, 3–4 — на втором; листы переключаются стрелками над предпросмотром.
• Если перед открытием старого проекта выбрать альбомный режим, четыре карточки автоматически распределятся по двум листам. Можно также открыть проект и затем переключить режим.
• Вы можете вводить и копировать три строки заголовка, менять размер каждой из них и отключать блок «К занятию». Значки возле полей вставляют и копируют текст через буфер обмена.
• Рядом с переключателем блока «К занятию» находятся номера других карточек. Нажмите номер, чтобы перенести из выбранной карточки три строки и их размеры.
• Кнопки «Отменить» и «Повторить» возвращают изменения текста, фотографий и карточек. Горячие клавиши: Ctrl+Z и Ctrl+Shift+Z или Ctrl+Y.

ФОТОГРАФИИ
• Добавьте одну, две или три фотографии, либо скомбинируйте фотографию и текст. Две фотографии могут стоять рядом или друг над другом. Три фотографии располагаются с небольшим наложением.
• Нажмите «Кадрировать и переместить фото» для отдельного окна предпросмотра. Увеличьте снимок и перетащите его мышью либо используйте ползунки. Если движение недоступно, сначала увеличьте фото или выберите режим «Обрезать края». Исходный файл при этом не изменяется.
• Изображение можно загрузить с диска или вставить из буфера обмена. Если браузер запросит доступ к буферу, разрешите его или скопируйте изображение и нажмите Ctrl+V вне текстового поля. Перед вставкой выберите кнопку вставки нужной фотографии.
• Браузеры надёжно поддерживают PNG и JPEG; HEIC и TIFF могут потребовать преобразования в PNG или JPEG. Если проект содержит неподдерживаемые изображения, он откроется и сохранит их данные, но для отображения на карточке такие изображения нужно заменить.

СОХРАНЕНИЕ И ПЕЧАТЬ
• «Сохранить проект» создаёт редактируемый JSON-файл с карточками и фотографиями. Обновлённая версия для Mac и эта Windows-версия открывают проекты друг друга, включая альбомный режим, три фотографии и кадрирование. Внешний вид текста может немного различаться из-за шрифтов и системы.
• «Сохранить PNG с полями» создаёт лист A4 для печати с выбранными полями; карточки получаются немного меньше A6.
• «Сохранить PNG: точный A6» создаёт лист A4 с карточками точного размера, без полей для принтера.
• Книжный PNG имеет размер 2480 × 3508 пикселей; альбомный — 3508 × 2480 пикселей. Разрешение — 300 dpi. Для печати выберите A4 и масштаб 100 %.
• Если альбомных листов два, программа попросит общее имя и папку, затем сохранит два отдельных PNG с окончаниями «-1» и «-2». Если браузер не поддерживает выбор папки, файлы сохраняются через загрузки браузера.
• В Edge и других браузерах с поддержкой выбора файла открывается диалог папки и имени. В остальных браузерах файл сохраняется через загрузки согласно настройкам браузера.

ВАЖНО
Приложение работает локально и не отправляет ваши данные в интернет. Это самостоятельная сборка без сертификата издателя: Windows может показать предупреждение при запуске. Интерфейс и автоматические проверки выполнены на Mac; запуск самого .exe на Windows пока не проверен.
